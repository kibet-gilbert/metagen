# Scripts:

1. `download_all_refseq.sh` : Downloads all refseq genome sequences at once
2. `download_prebuilt_ccmetagendbs.sh` : Downloads prebuilt (outdated) ccmetagen databases
3. `download_refseq.sh` : Downloads refseq genome sequences from "all" or select domains
4. `export_ncbi_blastdb_2_ccmetagen.sh` : exports sequences from a local NCBI BLAST database
5. `extract_rename_NCBIdb.py` : Does the same as "export_ncbi_blastdb_2_ccmetagen.sh" - more modular
